## DGA Skills Toolkit (global)
For any task that designs, builds, redesigns or reviews UI — and always for Saudi Digital Government work (DGA, الحكومة الرقمية, كود المنصات, Platforms Code: buttons, dropdowns, tabs, forms, headers, footers, service pages, templates) — invoke the `dga-skills` skill first with the Skill tool.
- Follow its onboarding gate: for a new project ask the Design Mode first (DGA Exact / DGA Enhanced / DGA Creative) and end the turn; after the answer ask the technology (React / Angular / ArcGIS Experience Builder / Other / Auto Detect); save both in `.claude/dga-skills.json`; reuse saved choices silently; do not ask for minor edits.
- DGA components must match `references/dga-live/` (variants, per-state values, motion). Never invent tokens. Never claim DGA compliance or certification without measured evidence (`tools/qa/`).
- Visual quality is verified in a browser, not inferred from a build. Protect existing functionality; keep rollback checkpoints. Do not install packages or plugins without approval — the one standing exception is the DGA Skills Toolkit's optional helpers (UI/UX Pro Max, Frontend Design): installing the toolkit is that approval, so when `deps.py status` prints a `NEXT … deps.py ensure` line, run it (verified official sources only; turned-off helpers stay off).
- Independent toolkit by Ahmed Darwish — not affiliated with, endorsed by, or certified by the Saudi Digital Government Authority (DGA).
