# Design Intelligence — fallback when original UI/UX Pro Max unavailable
Treat design as evidence-led decisions, not component recipes. Inspect:
- User journey: entry question, primary task, audience expertise, Arabic/LTR, context.
- Information architecture: content source, trust/verification, semantic hierarchy, map accuracy.
- Pattern suitability: editorial storytelling vs transactional dashboard vs policy/compliance vs map explorer.
- Visual grammar: compositions should DIFFER in reading order and focal point: (i) sectional editorial; (ii) cinematic spatial narrative; (iii) location-first atlas.
- For each of 3 concepts: above-the-fold thumbnail/preview, interaction storyboard, responsive strategy, accessibility risk, performance cost, DGA constraints and real assets.
- Evidence ledger: [OBSERVED CODE], [OBSERVED BROWSER], [USER SOURCE], [UPSTREAM], [DGA SNAPSHOT], [PROPOSAL].
- Reject a concept if core story could be transferred to any unrelated subject without visual changes.
- Never fabricate content metrics to improve visuals; use clearly marked dummy data only in isolated proof, not publish.
- Rule: DGA tokens/components are constraints; any upstream font or theme replacement requires explicit approval from user and compliance owner.
