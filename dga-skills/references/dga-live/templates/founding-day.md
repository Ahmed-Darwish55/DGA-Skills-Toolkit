> 1- سلوك البحث:

> الإكمال التلقائي

> قم بمعاينة النموذج الأولي في صفحة القالب لرؤية النتيجة.

> 1- Search Behavior:

> Auto Complete

> As the user types in the search field, the system should provide real-time suggestions based on the input. The suggestions should be relevant to the user's query and should update dynamically as the user continues typing.

> Delete Icon (Clear Button)

> The delete icon should appear when the user starts typing in the search field and should disappear when the field is empty. Clicking the icon clears the input field. The delete icon should be accessible via keyboard to meet accessibility standards.

> 8- Footer:

> Detach the Footer

> When detaching the footer, adhere strictly to the original structure and style. Do not alter the colors or fonts to maintain consistency with the overall design. The top footer is more link-intensive and complex, possibly designed for comprehensive navigation across a large site. The bottom footer, is more organized and user-friendly, with clear sections and reduced clutter, which improves the overall user experience and readability.

> Last Modified Date for the page

> Displaying the last modified date helps build user trust in the content, as it allows the user to know that the information on the page is up-to-date and reliable. It also enables them to quickly assess how recent the content is, which helps them decide whether to continue reading or search for more recent information elsewhere.

> Last Modified Date for the Platform

> Displaying the last modified date shows that the platform is under continuous development, which gives a positive impression that the platform is active. Users often prefer platforms that show signs of regular updates and ongoing improvements.

> حافظ على تنسيق متسق عبر التصميم. إذا تم وضع الزر أسفل المحتوى في قسم واحد، تأكد من تطبيق نفس الهيكل على جميع الأقسام.

> 9- “View All” Button:

> Using the “View All” Button

> The purpose of the “View All” button is to display additional content that is not shown in the default view of the page. The button should be placed in a prominent location within the design, close to the element that indicates the presence of additional content. It is important to ensure that users can see it clearly. Using a clear and straightforward label such as “View All” or “Show All” allows users to know exactly what will happen when they click the button.

> 10- Clickable Cards:

> The presence of a Call to Action (CTA) button in clickable cards

> In the design of clickable cards, if the goal is to encourage the user to take a specific action, the presence of a Call to Action (CTA) button is an essential part of the design. The button helps guide the user clearly and makes it easier for them to take the desired action. On the other hand, in cards intended for display only, the button can be omitted if the card provides sufficient information without the need for interaction.

> Unclickable Cards

> In the case of cards intended for display only, the button can be omitted if the card provides sufficient information without the need for interaction.

> 11- Mobile View:

> Long Title Case

> On mobile screens, when dealing with long titles and limited horizontal space, please position the button below the content. This will enhance readability and accessibility, making it easier for users to interact with the button without crowding the layout. A vertical stacking approach for the mobile layout is recommended to achieve this.

> Maintain a consistent layout across the design. If the button is placed below the content in one section, ensure that the same structure is applied to all sections.

> 14- Positioning:

> Case of Two Elements

> When there are two floating buttons, it is preferable to arrange them vertically, with one positioned above the other. This layout enhances page organization and makes it easier for users to interact with the elements without overlap or confusion. It also improves the user experience, especially on smaller screens, where improper arrangements may reduce button clarity and usability.

> Case of More Than Two Buttons

> When there are more than two floating elements, it is always recommended to use expandable menus or buttons with multiple options to reduce screen clutter, while also evaluating the importance of each element to set priorities. This arrangement enhances the user experience and improves accessibility to all elements. Additionally, it is preferable to organize these elements in a vertically sequential manner to ensure clarity and avoid overlap.
