> Platforms Code

> Guidelines

> Templates are used as essential tools to standardize and simplify processes in design. Template guidelines help improve performance, efficiency, and quality in many activities and tasks.

> 1- Search Inside FAQs:

> Search inside FAQs(optional)

> Recommended if there are more than 20 questions for easier access.

> Search behavior within FAQS

> It should display the results and update them in real-time based on the user's input (letter, word...). With Categories Display results in the "All" section, with highlighted matches as shown in the example. Without Categories Display results with highlighted matches.

> 2-Classification:

> List of categories

> Optional (but it is preferable to add the category if there are more than 20 questions in different fields for ease of access). The 'All' category must be added.

> Number of categories

> If it is a large screen, the number will be at the end of the screen, but for the phone screen it will not exceed five, after which the dropdown menu will be used.

> 3- Search Behavior:

> Auto Complete

> As the user types in the search field, the system should provide real-time suggestions based on the input. The suggestions should be relevant to the user's query and should update dynamically as the user continues typing.

> Delete Icon (Clear Button)

> The delete icon should appear when the user starts typing in the search field and should disappear when the field is empty. Clicking the icon clears the input field. The delete icon should be accessible via keyboard to meet accessibility standards.

> Preview the prototype to see the result.

> Detach Nav Header

> When detaching the nav-header, adhere strictly to the original structure and style. Do not alter the colors or fonts to maintain consistency with the overall design.

> Create Second Nav Header

> Design your second navigation header on condition by utilizing components from the library as foundational elements (atoms) and applying the background color specified from the design tokens.

> 7- Feedback:

> Feedback Section

> The most important element in the feedback section is the "Was this page useful?" question with the "Yes" and "No" buttons. By including options for specific reasons why the page was or wasn’t useful, it helps in pinpointing exact issues or strengths.

> 8- Footer:

> Detach the Footer

> When detaching the footer, adhere strictly to the original structure and style. Do not alter the colors or fonts to maintain consistency with the overall design. The top footer is more link-intensive and complex, possibly designed for comprehensive navigation across a large site. The bottom footer, is more organized and user-friendly, with clear sections and reduced clutter, which improves the overall user experience and readability.

> Last Modified Date for the page

> Displaying the last modified date helps build user trust in the content, as it allows the user to know that the information on the page is up-to-date and reliable. It also enables them to quickly assess how recent the content is, which helps them decide whether to continue reading or search for more recent information elsewhere.

> Last Modified Date for the Platform

> Displaying the last modified date shows that the platform is under continuous development, which gives a positive impression that the platform is active. Users often prefer platforms that show signs of regular updates and ongoing improvements.

> 9- Switching between languages:

> Switching between languages using a direct button.

> When only two languages are available (such as Arabic and English), using a direct button to change the language is the simplest and most effective way. The user can switch between languages by pressing the language change button. Once the language button is pressed, the page is immediately updated (or reloaded) to display all page elements in the selected language, including texts, menus, instructions, and even interactive contents such as buttons.

> Switching between languages using a drop-down menu.

> When there are more than two languages available, using a drop-down menu becomes a better and more organized option. This makes it easy for the user to see all available options and choose their preferred language.

> 10- “Clear Filter” Button:

> Adding a “Clear Filter” Button to Remove All Filter Options

> The button allows the user to clear all active filter options, restoring the display of all available content. This benefits users who want to see all results after a specific filter has been applied. The button should be placed in a clear location, close to the filter options themselves, so that users can easily see it while browsing the list. The text on the button should be clear and simple, such as “Clear Filter” or “Reset Filter”. This makes it easy for users to understand what the button does without any confusion.

> 11- Using a Dropdown Menu for Filtering:

> Using a Dropdown Menu for Filtering on Mobile Devices and Small Screens

> Because the available space for displaying content is very limited, using a dropdown menu allows filter options to be shown only when needed, helping to keep the screen organized and preventing clutter. The dropdown menu enables the user to focus on the main content without feeling visually overwhelmed by the constant presence of additional options.

> 12- Pagination to FAQ :

> Adding pagination to FAQ pages to organize content (optional).

> It is a means to organize and display content when there is a large amount of data or items that cannot be displayed on a single page. Pagination should be placed at the bottom of the content list so that the user can access it after browsing through the 10 available items. The page the user is currently on should be clearly highlighted, helping the user understand their current position within the page sequence. "Next" and "Previous" buttons (arrows) should be included to allow the user to quickly navigate between adjacent pages, providing a better user experience, especially if they don’t wish to jump to a distant specific page.

> 13- Display Filter Results:

> How to Display the Selected Filter Results

> After the user selects and confirms the filter options, the results are displayed in a list at the bottom of the search section, from right to left.

> Removing the Filter

> The delete icon must be displayed so that the user can remove the selected option after it has been applied. The data is updated accordingly based on this action.

> 14- Evaluation of the Submitted Answer :

> Evaluation of the Submitted Answer (Optional)

> It is possible to add evaluation to ensure the clarity of the answers for users and allow them to rephrase their responses based on their evaluations.

> Method of Displaying Evaluation

> It is preferable to display it below the answer section. It is also recommended to use the option shown in the image as an appropriate example for implementation. After receiving the user's rating, a message confirming the successful submission of the rating appears.

> 13- عرض نتائج التصفية:

> طريقة عرض نتائج التصفية المحددة

> بعد اختيار المستخدم لخيارات التصفية وتأكيد تطبيقها، يتم عرض النتائج في الصف السفلي من قسم البحث من اليمين إلى اليسار.

> حذف الخيار

> يجب إظهار أيقونة الحذف بجانب كل خيار، بحيث تتيح للمستخدم حذف الخيار بعد تطبيقه، ويتم تحديث البيانات بناءً على ذلك.

> 14- تقييم الاجابة المقدمة:

> تقييم الاجابة المقدمة (اختياري)

> يمكن إضافة خيار التقييم للتأكد من وضوح الأجوبة للمستخدمين وإعادة صياغتها استنادًا إلى تقييماتهم.

> طريقة عرض التقييم

> يُفضّل عرض التقييم في أسفل قسم الإجابة، ويُنصح باستخدام الخيار المعروض في الصورة كمثال مناسب للتطبيق. بعد تلقي التقييم من المستخدم، تظهر رسالة تؤكد نجاح إرسال التقييم.

> 12- ترقيم الأسئلة الشائعة:

> إضافة ترقيم صفحات الأسئلة الشائعة لتنظيم المحتوى (اختياري)

> يعد ترقيم الصفحات وسيلة لتنظيم وعرض المحتوى عندما يكون هناك كمية كبيرة من البيانات أو العناصر التي لا يمكن عرضها في صفحة واحدة. يجب وضع ترقيم الصفحات في الجزء السفلي من قائمة المحتوى بحيث يصل إليه المستخدم بعد تصفح 10 عناصر متاحة. الصفحة التي يتواجد فيها المستخدم حاليًا يجب أن تكون مميزة بوضوح، مما يساعد المستخدم على معرفة موقعه الحالي ضمن تسلسل الصفحات. يجب تضمين أزرار (أسهم) "التالي" و"السابق" للسماح للمستخدم بالتنقل بسرعة بين الصفحات المجاورة، مما يوفر تجربة مستخدم أفضل، خاصة إذا لم يكن يريد الانتقال إلى صفحة بعيدة محددة.

> 11- استخدام القائمة المنسدلة للتصفية:

> استخدام القائمة المنسدلة (Drop-down Menu) للتصفية:

> يتيح استخدام القائمة المنسدلة عرض خيارات التصفية عند الحاجة فقط، مما يساعد على تنظيم الشاشة ويمنع ازدحامها. كما يتيح للمستخدم التركيز على المحتوى الرئيسي دون الشعور بالازدحام البصري الناتج عن ظهور خيارات إضافية بشكل دائم.

> قم بمعاينة النموذج الأولي في صفحة القالب لرؤية النتيجة.

> 10- زر “إزالة التصفية”:

> إضافة زر “إزالة التصفية” لإلغاء جميع خيارات التصفية

> يسمح هذا الزر للمستخدم بإلغاء جميع خيارات التصفية المفعّلة، مما يعيد عرض كافة المحتويات المتاحة. هذا الخيار مفيد للمستخدمين الذين يرغبون في رؤية جميع النتائج بعد تطبيق تصفية معينة. يجب وضع الزر في مكان واضح وقريب من خيارات التصفية، بحيث يسهل على المستخدم رؤيته عند تصفح القائمة. ينبغي أن يكون النص على الزر واضحًا وبسيطًا، مثل "إزالة التصفية" أو "إعادة تعيين التصفية"، وذلك ليتمكن المستخدم من فهم وظيفة الزر دون لبس.

> 9- التبديل بين اللغات:

> التبديل بين اللغات باستخدام زر مباشر

> عندما تكون هناك لغتان فقط متاحتان (مثل العربية والإنجليزية)، فإن استخدام زر مباشر لتغيير اللغة يكون الحل الأبسط والأكثر فعالية. حيث يمكن للمستخدم التبديل بين اللغات من خلال الضغط على زر تغيير اللغة. بمجرد الضغط على زر اللغة، يتم تحديث الصفحة فورًا (أو إعادة تحميلها) لتُعرض كافة عناصر الصفحة باللغة المختارة، بما في ذلك النصوص، القوائم، التعليمات، وحتى المحتويات التفاعلية مثل الأزرار.

> التبديل بين اللغات باستخدام القائمة المنسدلة (drop-down menu)

> عندما يكون هناك أكثر من لغتين، يصبح استخدام قائمة منسدلة خيارًا أفضل وأكثر تنظيمًا. هذا يجعل من السهل على المستخدم رؤية جميع الخيارات المتاحة واختيار اللغة المفضلة

> 8- التذييل:

> فصل التذييل (Detach)

> عند فصل التذييل، التزم بدقة بالهيكل والأسلوب الأصليين. لا تقم بتغيير الألوان أو الخطوط للحفاظ على التناسق مع التصميم العام. حيث ان التذييل يحتوي على المزيد من الروابط وهو أكثر تعقيدًا، وقد تم تصميمه لتسهيل التنقل الشامل عبر موقع كبير. أما التذييل الاصلي، فهو أكثر تنظيمًا وسهولة في الاستخدام، مع أقسام واضحة وتقليل للتعقيد، مما يحسن من تجربة المستخدم بشكل عام وسهولة القراءة.

> تاريخ آخر تعديل للصفحة

> عرض تاريخ آخر تعديل يساعد في بناء ثقة المستخدم بالمحتوى، حيث يعلم المستخدم أن المعلومات الموجودة على الصفحة حديثة وموثوقة، ويمكنه تقييم مدى حداثة المحتوى بسرعة، مما يساعده في اتخاذ قرار بمتابعة القراءة أو البحث عن معلومات أحدث في مكان آخر.

> تاريخ آخر تعديل للمنصة

> عرض تاريخ آخر تعديل يُظهر أن المنصة في حالة تطوير دائم، وهذا يعطي إنطباعاً إيجابياً بأن المنصة نشطة. المستخدمون غالبًا ما يفضلون المنصات التي تُظهر علامات على التحديث المنتظم والتطوير المستمر

> 15- Digital Stamp:

> The ending of the website's URL

> The type of stamp is determined based on the ending of the website URL, as follows: gov.sa: Used for official platforms belonging to government entities. Example: https://example.gov.sa med.sa: Used for medical platforms. Example: https://example.med.sa edu.sa or sch.sa: Used for educational platforms. Example: https://example.edu.sa or https://example.sch.sa org.sa: Used for non-profit organizations. Example: https://example.org.sa sa: Used for official platforms related to activities and initiatives. Example: https://example.sa

> After adding the digital stamp at the top of the page, the stamp in the footer should be removed.

> 15- الختم الرقمي:

> نهاية رابط المنصة

> يتم تحديد نوع الختم بناءً على نهاية رابط الموقع الإلكتروني (URL) كما يلي: gov.sa: يُستخدم للمنصات الرسمية التابعة للجهات الحكومية، مثل: https://example.gov.sa med.sa: يُستخدم للمنصات الطبية، مثل: https://example.med.sa edu.sa أو sch.sa: يُستخدم للمنصات التعليمية، مثل: https://example.edu.sa أو https://example.sch.sa org.sa: يُستخدم للمؤسسات غير الربحية، مثل: https://example.org.sa sa.: يُستخدم للمنصات الرسمية الخاصة بالأنشطة والمبادرات، مثل: https://example.sa
