> Installing and publishing the foundations and icons library files to design files.

> To use the UI kit library files correctly, you must start by installing the foundation library and the icon library files first. These libraries contain atomic-level elements that form the base for the UI component library.

> Open Figma.

> Open Figma and log in to your account.

> Import the “PC 1.0 Foundations” and “PC 1.0 icons” library files on your project folder.

> Import the “PC 1.0 Foundations” and “PC 1.0 Icons” library files into your project folder. Ensure that you have created both a team file and a project folder within the team file.

> Open the “PC 1.0 Foundations” and “PC 1.0 icons” library files on Figma.

> Open the “PC 1.0 Foundations” and “PC 1.0 icons” library files, which will be used in another file (your Figma design file).

> Publish the “PC 1.0 Foundations” and “PC 1.0 icons” library files on Figma.

> Publish the “PC 1.0 Foundations” and “PC 1.0 icons” library files by clicking on the library icon at the top of the screen, then publish the library to the team that contains the design files.

> Add the “PC 1.0 Foundations” and “PC 1.0 icons” library files to your design file.

> To add the assets library files to the design file, use the library files icon at the top of the screen, then add the “PC 1.0 Components - Desktop” library by clicking on 'Add to file' button.

> Installing and publishing the components library file to your design files.

> Now, let's install our components library. It contains all the UI elements you need to create an exceptional digital experience for your products.

> Import the PC 1.0 Components - Desktop” or “PC 1.0 Components - Mobile” on your project folder.

> Import the “PC 1.0 Components - Desktop” or “PC 1.0 Components - Mobile” library files into your project folder. Ensure that you have created both a team file and a project folder within the team file.

> Open the “PC 1.0 Components - Desktop” or “PC 1.0 Components - Mobile” library file on Figma.

> Open the “PC 1.0 Components - Desktop” or “PC 1.0 Components - Mobile” library file, which will be used in another file (your Figma design file).

> Publish the “PC 1.0 Components - Desktop” or “PC 1.0 Components - Mobile” library file.

> Publish the “PC 1.0 Components - Desktop” or “PC 1.0 Components - Mobile” library file by clicking on the Library icon at the top of the screen, then publish the library to the team that contains your design files.

> Add the “PC 1.0 Components - Desktop” Library file to your design file.

> To add the Component library file to the design file, click on the Library icon at the top of the screen, then add the “PC 1.0 Components - Desktop” library by clicking on “Add to file” button.

> How to Use the Design Assets

> This guide offers concise instructions to brows and use the national design system Platform code visual assets into their projects.

> Start using design assets and create impactful solutions

> After adding the libraries to your design files you can browse all the UI elements, foundation (Design language), starting from text styles to all tokens such colors tokens and spacing tokens.

> You can browse the components through the “Assets” tab on the left side of the screen.

> In the design file, you can browse and add components from the library to your design file through the ”Assets” tab.

> You can browse and try with the design language (Foundations) on the right side of the screen.

> For example, when selecting any Text element, you can browse all text styles in the “PC 1.0 Components - Desktop” library file on the right side of the screen. Similarly, when selecting any Frame element, you can explore the colors variables to apply to the selected frame.

> A dictionary for design decisions, All design tokens in one place

> Discover all design tokens, from colors to spacing values for different device sizes, alongside radius and width options, conveniently consolidated in one place.

> Library Migration

> This guide offers clear instructions for updating the libraries with new versions, ensuring a smooth migration.

> Import and publish the new library file to your design files.

> To update the library correctly, you must start by installing and publish the new library, and then replace the old one with new one.

> Import the new library file on your project folder.

> Import the new library file into your project folder. Ensure that you have created both a team file and a project folder within the team file.

> Open the new library file on Figma.

> Open the new library file, which will be used in another file (your Figma design file).

> Publish the the new library file to your team

> Publish the new library file by clicking on the library icon at the top of the screen, then publish the library to the team that contains the design files.

> Swapping the old library with the new library

> Now, let's swap the old library with the new library to seamlessly update your design assets.

> Browse the added library

> Click on the library icon at the top of the screen to view all the added libraries. click on the library you want to replace.

> Choose the new library to swap with the old one.

> Choose the new library to replace the current one for a seamless update, and the components used in the file will be automatically updated.

> Remember

> When swapping, Figma updates styles and components with matching names, including sets and variants. Ensure component names haven't changed in the previous library.
