# DGA component registry

`components.json` lists **every component set** in the official Web and Mobile libraries (extracted live 2026-10-17): name, page, Figma node, variant axes (with every option), other properties, and paths to the spec (`.md`) and raw data (`.json`).

Coverage = `verified-live-2026-10-17` for all entries. Use it to answer "does DGA have component X / state Y?" quickly, then open the spec.
