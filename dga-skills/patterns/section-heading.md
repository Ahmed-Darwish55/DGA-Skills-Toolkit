# Section heading — `SectionHeading` / `sectionHeading()`
Figma: "Section Template - Desktop/Mobile" instance used by templates (title + description + optional link, 1440×88).
Anatomy: `.ah-heading` flex (space-between, align end; column on mobile) → `.ah-heading__text` (h2 Display sm `--text-display`, p Text lg `--text-primary-paragraph`) → optional `dga-link` (no icon: PKG-LINK-01 prints `iconType` as text in core 0.0.52).
`center` option for centred sections (FAQ contact). Heading level configurable (`level`), default h2 under the page h1.
