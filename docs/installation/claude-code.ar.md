# تثبيت DGA Skills Toolkit في Claude Code — أمر واحد

> English: [INSTALLATION.md](../INSTALLATION.md)

> مشروع مستقل، غير تابع لهيئة الحكومة الرقمية ولا معتمد منها.

## المطلوب قبل ما تبدأ
- Claude Code مثبّت ومسجّل دخول (`claude --version` بيشتغل).
- Python 3.8 أو أحدث (`python3 --version`، وعلى ويندوز `py --version`).
- إنترنت، علشان الأداتين المساعدتين بيتنزلوا من مصادرهم الرسمية.

## الأمر الواحد
نزّل المستودع (أو فك `DGA-Skills-Toolkit-V5.0.3-FINAL.zip` من صفحة الإصدار)، وادخل على الفولدر، واكتب:

```bash
git clone https://github.com/Ahmed-Darwish55/DGA-Skills-Toolkit.git
cd DGA-Skills-Toolkit
python3 install.py install
```
على ويندوز: `.\install.ps1 install` أو `install.cmd install`

**مفيش أسئلة ولا خطوات تانية.** الأمر ده بيعمل كل حاجة في عملية واحدة:
1. **بيثبّت الأداة نفسها** (`dga-skills`) ويتحقق من سلامة كل ملف. لو عندك الاسم القديم `ahmed-skills` (legacy)، بيعمله نسخة احتياطية ويستبدله.
2. **بيدوّر على الأداتين المساعدتين:** Frontend Design (من Anthropic، رخصة Apache-2.0) وUI/UX Pro Max (من NextLevelBuilder، رخصة MIT).
3. **أي أداة ناقصة بيثبّتها لوحده:**
   - **بيتأكد من المصدر الأول:** اسم المتجر، وإن الأداة موجودة فيه، ونص الرخصة. لو أي حاجة مش مطابقة **ما بيثبّتش**.
   - بعدها بيثبّتها بأمر Claude Code الرسمي `claude plugin install`.
   - كل خطوة بتتطبع قدامك وبتتسجل في `~/.claude/dga-skills-install/dependencies-state.json`.
4. لو أداة موجودة وإنت **قافلها**، بيسيبها مقفولة. ده قرارك، وهو مش هيغيّره.

بعد ما يخلص: **افتح جلسة Claude Code جديدة.**

### لو مش عايز الأدوات المساعدة
```bash
python3 install.py install --no-deps
```
أو حط `DGA_SKILLS_NO_AUTO_DEPS=1` في البيئة. الأداة بتشتغل من غيرهم بقواعد بديلة جوّاها.

### لو حاجة ما اتثبّتتش
| السبب | اللي بيحصل |
|---|---|
| الأمر `claude` مش موجود على الجهاز | الأداة بتتثبت عادي، وبيقولك السبب. بعد ما تثبّت Claude Code شغّل: `python3 install.py deps ensure` |
| مفيش إنترنت أو المصدر رفض التحقق | ما بيثبّتش حاجة، والأداة بتشغّل البديل المحلي. لما النت يرجع: `python3 install.py deps ensure --force` |
| نسيت تثبّتهم أو ثبّت بـ`--no-deps` | أول طلب تصميم، الأداة نفسها بتشغّل `deps.py ensure`. Claude Code هيطلب موافقتك على الأمر مرة واحدة، والأدوات تشتغل من الجلسة اللي بعدها. |

## أوامر مفيدة بعدين
| الأمر | بيعمل إيه |
|---|---|
| `python3 install.py deps status` | إيه المثبت وإيه الناقص وإيه المقفول (من غير أي تغيير) |
| `python3 install.py deps ensure` | يثبّت الناقص لوحده (مصادر رسمية متحقق منها) |
| `python3 install.py deps setup` | بيسألك `[y/N]` قبل كل أداة |
| `python3 install.py deps verify-source` | يتأكد من مصدر ورخصة الأدوات المساعدة |
| `python3 install.py verify` | يتأكد إن ملفات الأداة سليمة |
| `python3 install.py rollback` | يرجّع آخر نسخة احتياطية |

## الأداة شغالة؟
افتح أي مشروع واكتب طلب واجهة عادي، مثلًا: «اعمل dropdown بتاع الحكومة الرقمية». المفروض:
- الأداة تشتغل لوحدها من غير ما تذكر اسمها؛
- أول سؤال يكون **نمط التصميم** بس (Exact / Enhanced / Creative)، وفي الرسالة اللي بعدها تسأل عن التقنية.
