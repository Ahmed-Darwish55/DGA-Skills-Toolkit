# تثبيت DGA Skills Toolkit في Claude Desktop / Cowork

> مشروع مستقل، غير تابع لهيئة الحكومة الرقمية ولا معتمد منها.

## اللي محتاجه
- اشتراك Pro أو Max أو Team أو Enterprise، وتنفيذ الكود (Code execution) شغال في الإعدادات.
- الملف `DGA-Skills-Toolkit-V5.0.3-COWORK-UPLOAD.zip` من [صفحة الإصدار](https://github.com/Ahmed-Darwish55/DGA-Skills-Toolkit/releases/tag/v5.0.3) (حوالي 3 MB مضغوط، 10.6 MB بعد الفك، 167 ملف). جواه فولدر `dga-skills/` فيه **كل حاجة** بدون أي حذف:
  - القواعد؛
  - مراجع DGA وبياناتها كاملة؛
  - السجلات والأنماط والقوالب والأدوات.

## الخطوة الوحيدة: ارفع الـskill مرة واحدة
1. افتح Claude ← **Customize ← Skills**.
2. لو موجود الـskill القديم **ahmed-skills** (legacy)، اقفله، عشان ما يتنافسش مع الجديد.
3. **+ ← Upload skill** واختار ملف الـZIP. الـskill بيتفعّل لوحده.
4. افتح مهمة Cowork جديدة واكتب: «اعمل dropdown بتاع الحكومة الرقمية».

**مش مطلوب منك ترفع SKILL.md ولا المراجع لوحدهم**، ولا تعمل أي إعداد تاني.

## الأدوات المساعدة: مفيش حاجة تعملها
- لو **UI/UX Pro Max** أو **Frontend Design** مفعّلين في حسابك، الأداة **بتلاقيهم لوحدها وتستخدمهم**. Claude Desktop بيعمل لهم sync جوه الجلسة (`skills/synced/`)، والأداة بتقرا القايمة دي.
- لو مش موجودين أو مقفولين، الأداة بتشتغل بالبديل اللي جوّاها **من غير ما تسألك تثبّت حاجة**، وبتكتب سطر واحد للمعلومة بس.
- لو أداة مثبّتة بس **مقفولة**، الأداة ما بتقولش عليها «مش مثبّتة». ووقتها فيه حالتين:
  - لو Cowork بيبيّن إنها مقفولة: `INSTALLED BUT DISABLED`؛
  - لو مش بيبيّن الأدوات المقفولة: `NOT AVAILABLE IN THIS SESSION (not installed, or turned off)`.

### قيد المنصة (مكتوب بوضوح بدل ما ندّعي حاجة مش حقيقية)
في Cowork، أي skill **مش بيقدر** يثبّت أو يفعّل skill تاني، والأداة ما بتحاولش تتحايل على ده. عشان كده التثبيت التلقائي للأدوات المساعدة موجود في Claude Code بس. في Cowork الأداة **مستقلة** ومش معتمدة عليهم.

لو **إنت** عايز الإضافات دي (اختياري تمامًا):
| الأداة | الرخصة | إزاي تضيفها |
|---|---|---|
| Frontend Design (Anthropic) | Apache-2.0 | **Customize ← Plugins ← Add marketplace** ← `anthropics/claude-plugins-official` ← `frontend-design` |
| UI/UX Pro Max (NextLevelBuilder) | MIT | **Customize ← Plugins ← Add marketplace** ← `nextlevelbuilder/ui-ux-pro-max-skill` ← `ui-ux-pro-max` |

## إزاي الحزمة بتعدّي حدود الرفع من غير ما نحذف حاجة
Cowork بيرفض الـZIP لو فيه:
- أكتر من 200 ملف؛
- أو حجمه بعد الفك أكتر من 30 MB؛
- أو فيه أكتر من SKILL.md؛
- أو في أسماء الملفات حرف `@`.

الحزمة بتخزّن نفس البايتات بشكل أصغر من غير ما تحذف حاجة:
- صفحات المراجع (web/mobile/templates) اتجمعت في 3 ملفات Markdown: `WEB-CATALOG.md`، `MOBILE-CATALOG.md`، `TEMPLATES-CATALOG.md`.
- البيانات الخام اتحطت في ملف واحد مضغوط: `DATA-PACK.json.gz`.
- `platformscode-core@0.0.52.json` بقى اسمه `platformscode-core-v0.0.52.json`.

كل ملف أصلي محفوظ ببصمته (SHA-256)، وأدوات الحزمة بتقراه في الحالتين. لو عايز تتأكد، اكتب في Cowork: «شغّل `tools/dga_res.py verify`».

## اختبار القبول (اعمله مرة واحدة وابعتلي النتيجة)
| # | الخطوة | النجاح |
|---|---|---|
| C1 | ارفع الـZIP | الرفع بيقبل الملف، و`dga-skills` بيظهر ومتفعّل |
| C2 | مهمة جديدة: «اعمل dropdown بتاع الحكومة الرقمية» | الأداة تشتغل لوحدها، وأول سؤال **نمط التصميم** بس |
| C3 | نفس المهمة | **ما تطلبش منك** ترفع SKILL.md أو المراجع أو تعمل أي إعداد |
| C4 | «حسب كود المنصات، إيه حالات مكون الـDropdown؟» | الإجابة من المراجع اللي جوه الأداة (`WEB-CATALOG.md` أو `dga_res.py cat …`) |
| C5 | والأدوات المساعدة **مفعّلة**: «صمّم Hero إبداعي لخدمة حكومية» | الأداة تقول إنها `INSTALLED` وتستدعيها فعلًا |
| C6 | **اقفل** UI/UX Pro Max من Customize وكرّر C5 | الحالة **مش** `NOT INSTALLED`. الأداة تكمّل بالبديل من غير ما تطلب منك تثبّت حاجة |
| C7 | «شغّل `tools/dga_res.py verify`» | `… 205 packed files, 0 bad → OK` |

## حدود معروفة
- رفع ZIP الإصدار 5.0.3 على حساب Cowork لسه ما اتأكدش.
- الأداة متجهّزة للحالتين اللي ممكن Cowork يعرض بيهم الـskill **المقفول** جوه الجلسة، وخطوة C6 هي اللي بتوضح ده عندك.
- حدود الرفع: 200 ملف، و30 MB، وملف SKILL.md واحد، ومن غير `@` في أسماء الملفات.
