# Templates

The toolkit knows all **20 page templates** of the DGA Platforms Code. Each template has a reference page in [`dga-skills/references/dga-live/templates/`](../dga-skills/references/dga-live/templates/) with its section structure, extracted from the DGA Figma Community files. The full status map is [`dga-skills/lib/templates/templates-map.json`](../dga-skills/lib/templates/templates-map.json).

There are three levels of support:

| Level | Meaning |
|---|---|
| **Implemented** | a ready page or block in `lib/templates` or `lib/patterns` |
| **Skeleton** | generated by `tools/new_template.py`: it compiles, renders every section of the template with labelled placeholder content, and marks what you must fill with `TODO(content)`. It is a **starting point, not a verified page** |
| **Builder only** | the building blocks exist, but the page is not assembled for that technology |

## Generate a skeleton

```bash
python3 dga-skills/tools/new_template.py --list
python3 dga-skills/tools/new_template.py --template national-day --dest src/pages --lib ../dga-skills/patterns/react
python3 dga-skills/tools/new_template.py --all --dest src/pages --lib ../dga-skills/patterns/react
```

After installation the tool is at `~/.claude/skills/dga-skills/tools/new_template.py`. The generator writes React pages; `--lib` is the import path from the generated page to the copied `patterns/react` folder.

## Use the implemented pages

React:

```jsx
import { Home, Services, Service, Faq, FormPage, SearchPage, ContactPage, NotFound } from './dga-skills/templates/react/index.js';
```

Vanilla:

```js
import { home, services, service, faq, notFound } from './dga-skills/templates/vanilla/index.js';
```

Every page takes its header, navigation and footer from the site configuration; see [GETTING-STARTED.md](GETTING-STARTED.md#5-one-site-configuration-all-technologies).
